# 精准猎头流

## 触发与边界
当用户说「新岗位」「开一个单」「用精准猎头流」，或粘贴 JD 并要求按猎头流程推进时使用。目标用户是 **Codex 桌面版**：在对应步骤自行创建或更新 Automations；CLI-only 不是目标。Automations 只读写本地岗位文件，**不自动外呼、不自动推客户**，任何外发和拨打都由用户人工完成。

## 一岗一目录与隐私
优先在用户工作区创建 `.hj-skill-local/precision-recruiter-flow/jobs/<slug>/`，`<slug>` 用小写字母、数字和短横线。不得把简历、候选人记录、通话日志或公司内部资料提交到 git。开岗时从 `references/templates/` 复制以下结构：

```
01-职位理解.md  02-标准简历.md  03-候选人-list.md  04-电话话术.md
05-搜索清单.md  06-目标公司-核心人.md  07-通话记录.md
resumes/  reviews/
```

01 可持续迭代；07 是流水，不能塞进 03；模板全部为中文。

## 强制流程
1. 建目录并复制模板；读取 JD 和已有本地资料。
2. 写/改 `01-职位理解.md`，向用户展示理解并等待用户确认“理解 OK”。未确认不得定标杆。
3. 用户确认后，在 **Codex Desktop** 创建/更新「5 分钟定标杆」Automation。它读取 01、leader 样板/自搜高匹配/客户面到 offer/在岗画像等输入，最多 5 分钟，产出 `02-标准简历.md`，并回写 01 的确认状态。标杆未确认不得开始 sourcing。
4. 标杆确认后创建/更新「Sourcing 2 小时」Automation，目标约 10 个准人；读取 01、02、06，拆分公司/业务线/级别/地点/薪资，更新 05、03 和 `resumes/`。人工肉眼搜建议 ≤4h/日；不得宽泛搜索。
5. 按 `04-电话话术.md` 人工打电话；每次把时间、候选人、结果、要点纪要、下次动作写入 `07-通话记录.md`，并汇总更新 03 的通话次数、最近触达日和状态。
6. 岗位进行中，在桌面版创建/更新每日 **12:00、18:00**「复盘」Automation，读取 01、03、05、07 和当天已有 reviews，写入 `reviews/YYYY-MM-DD-HH-复盘.md`。

## Automations（Codex 桌面版）
Skill 在步骤 3、4、6 明确要求 Codex Desktop 自行创建或更新 Automation；用户可在桌面版 Automations 面板查看、暂停和调整。每条 Automation 必须包含触发、prompt 要点及读写边界：

- **5 分钟定标杆**：触发=用户确认职位理解后立即运行一次；prompt=读取 01 与用户提供的四类标杆来源，提炼可验证硬条件、加分项、排除项，5 分钟内写 02 并回写 01；读=01、输入资料，写=02、01。
- **Sourcing 2 小时**：触发=02 标杆确认后运行一次，持续约 2 小时；prompt=按公司/业务线/级别/地点/薪资分组，目标约 10 准人，记录证据和来源；读=01、02、06，写=05、03、`resumes/`。不拨号、不发送、不推客户。
- **12:00 / 18:00 复盘**：触发=岗位进行中每天本地时间 12:00、18:00；prompt=检查准人进度、有效呼出、搜索是否超时、标杆/职位理解是否回写，提出下一步 1–2 条；读=01、03、05、07，写=`reviews/YYYY-MM-DD-HH-复盘.md`。

Automation prompt 应要求保留人工确认点、使用当前岗位目录、不要猜测缺失信息。若桌面版不允许 skill 直接创建，立即把上述触发和 prompt 以可复制内容展示给用户，让用户在 Automations 面板创建。

## 03 候选人主表与状态机
`03-候选人-list.md` 必须有字段：姓名、电话/微信、来源、当前公司/岗位/级别/地点、状态、匹配证据、备注、最近触达日、下次触达日、通话次数、简历路径。状态只能使用：

`待建联 → 待打 → 已打-跟进中 → 感兴趣 → 已推客户 → 面试中 → offer → 入职 → 暂缓 → 丢弃`

`06-目标公司-核心人.md` 是目标公司地图：在岗对标人、上级/协作、同公司同方向暂未触达、行业标杆核心人、可选离职不久；字段必须含“是否已转入 list”。它可先于 03 使用；开始打后把人转入 03，并在 06 标“已转入 list”。03 只放本单已决定建联、在打或在推的人。

## 硬规则与复盘
搜索必须拆公司/业务线/级别/地点/薪资，禁止过宽搜；定标杆 ≤5 分钟；定标杆后 2h 冲约 10 准人；人工肉眼搜建议 ≤4h/日；日有效呼出参考 20–30。复盘模板必须检查：准人进度、呼出、是否搜超时、标杆/职位理解是否回写、下一步 1–2 条。
